
**單元三－2｜攝影 Photography：從看見到拍出好照片**

**一、學習目標**

完成本單元後，學生能夠：

- 用主體、構圖、光線與背景分析一張照片。
- 使用手機調整對焦、曝光與拍攝角度。
- 分辨背景失焦、動態模糊與手震。
- 拍攝校園或生活中的影像，並說明自己的創作選擇。
- 為後續合成準備合適的照片素材。

**二、什麼是一張好照片？**

原本「最重要的，都要是美的照片」可以保留為課堂口號，再加上具體標準：

> **主體看得見、畫面有安排、光線有目的、照片有想法。**

拍攝前，先問自己四個問題：

| 問題 | 自我檢查 |
|---|---|
| 我想讓觀眾看什麼？ | 是否有明確主體？ |
| 視線會先落在哪裡？ | 最亮、最大或最鮮豔的地方是不是重點？ |
| 有什麼可以拿掉？ | 雜物、路人或畫面邊緣是否干擾主體？ |
| 我想傳達什麼？ | 安靜、熱鬧、巨大、孤單、清新，還是幽默？ |

「好看」可以有不同風格；學生需要能說出，自己的安排如何服務主題。

**三、先看作品，再學方法**

| 作品參考 | 觀察重點 | 課堂提問 |
|---|---|---|
| 田中達也《MINIATURE CALENDAR》 | 日常物件、比例轉換、微型場景 | 一個日用品，能被想像成什麼風景？ |
| Erik Johansson 超現實攝影，例如《Full Moon Service》 | 照片合成、想像力與真實感 | 不可能的場景，為什麼仍然讓人相信？ |
| 原有學生優良作品 | 校園取景、有限器材、創意表現 | 同一個地點，你會怎麼重新拍攝？ |

田中達也的作品適合引導「物件聯想」；Johansson 則以照片組合出超現實場景，適合銜接後續合成課程。作品連結：[MINIATURE CALENDAR](https://miniature-calendar.com/)、[Erik Johansson 作品集](https://www.erikjo.com/work)、[創作理念與流程](https://www.erikjo.com/about/)。

**一張作品，三個觀察。**

例如「構圖選擇」、「光線線索」與「創意轉換」

**四、手機攝影的基本流程**

> **擦鏡頭 → 找主體 → 看背景 → 選角度 → 對焦 → 調曝光 → 穩定拍攝 → 放大檢查**

1. **擦乾淨鏡頭**：避免油污造成霧感與光暈。
2. **開啟格線**：輔助水平、垂直與主體位置。
3. **先移動人，再改變變焦**：前後左右走幾步，觀察背景與透視的變化。
4. **點選主體對焦**：人物通常以眼睛為重點；商品選擇商標或重要細節。
5. **視需要鎖定對焦／曝光**：適合固定距離的連續拍攝；主體距離改變時要重新對焦。操作依手機而異。
6. **調整曝光**：確認主體亮度，也檢查天空、白衣與反光處是否失去細節。
7. **穩住手機**：雙手持握、手肘靠近身體，必要時靠牆或使用腳架。
8. **拍後放大檢查**：確認焦點、手震、背景雜物與畫面邊緣。

以 iPhone 為例，相機提供對焦、曝光調整與鎖定功能；授課時可依學生手機示範對應操作。[Apple 相機工具說明](https://support.apple.com/zh-tw/guide/iphone/iph3dc593597/27/ios/27)

**五、構圖：安排觀眾看照片的順序**

| 方法 | 核心概念 | 校園練習 |
|---|---|---|
| 三分法 Rule of Thirds | 將主體放在線條或交點附近 | 人物與操場、樹與天空 |
| 中央與對稱 Center / Symmetry | 利用平衡與秩序集中視線 | 校門、走廊、樓梯 |
| 引導線 Leading Lines | 讓線條帶領視線走向主體 | 路面、欄杆、建築線條 |
| 框景 Framing | 使用前景包圍主體 | 門、窗、樹枝 |
| 留白 Negative Space | 以較單純的區域凸顯主體 | 大片天空中的小人物 |
| 前、中、後景 Layers | 利用不同距離建立空間感 | 前景樹葉、中景人物、遠景建築 |
| 重複與節奏 Pattern | 從規律中找秩序或差異 | 窗戶、椅子、磁磚 |
| 色彩對比 Color Contrast | 用顏色差異吸引注意 | 綠葉中的紅色物件 |

三分法是構圖起點，對稱或中央構圖也能有效表達主題。可用同一場景比較兩種安排。[Adobe 三分法教學](https://www.adobe.com/au/creativecloud/photography/discover/rule-of-thirds.html)

原有中文教材可保留作延伸閱讀：[LOFI 九種構圖法](https://lofi-house.com/blog/photo-composition/)。

**六、光線、景深與動態：新增的基礎觀念**

**光線方向**

- **順光**：光從拍攝者後方照向主體，容易看清顏色與細節。
- **側光**：光從側面照入，適合表現立體感與紋理。
- **逆光**：光源位於主體後方，可拍輪廓光、透光葉片或剪影。
- **柔光與硬光**：觀察影子邊緣；邊緣柔和或清楚，會產生不同感受。

**曝光三要素，先理解效果**

| 項目 | 主要影響 | 初學者理解方式 |
|---|---|---|
| 光圈 Aperture | 進光量與景深 | 其他條件相近時，大光圈通常讓清楚範圍較淺 |
| 快門 Shutter Speed | 曝光時間與動態呈現 | 快快門凝結動作，慢快門可能留下移動痕跡 |
| ISO | 影像亮度設定與畫質取捨 | 提高 ISO 常能配合較快快門，但可能增加可見雜訊 |

手機自動模式通常代為安排這些設定；許多手機鏡頭的實體光圈固定，因此入門實作先掌握光線、距離、穩定與曝光補償即可。[Adobe 曝光設定](https://www.adobe.com/creativecloud/photography/hub/guides/camera-exposure-camera-settings.html)

**三種「模糊」要分清楚**

| 類型 | 原因 | 畫面特徵 |
|---|---|---|
| 背景失焦 | 背景落在景深之外 | 主體清楚，背景柔化 |
| 動態模糊 | 曝光期間主體或相機移動 | 移動方向形成拖影 |
| 手震 | 拍攝時不受控的晃動 | 原本想拍清楚的區域也模糊 |

拍攝背景失焦時，可在能正常對焦的範圍內靠近主體，並拉開主體與背景的距離。**鎖住焦點本身不會製造散景。**手機人像模式則可能以運算模擬模糊，應檢查髮絲與物件邊緣。[Adobe 淺景深教學](https://www.adobe.com/creativecloud/photography/discover/shallow-depth-of-field.html)

**七、校園攝影任務：保留原有 21 題並重新說明**

下表是依原題改編的課堂任務。

| 編號 | 主題／英文 | 任務與成功條件 |
|---|---|---|
| 1 | 俯拍 High-angle Shot | 從安全位置向下拍，讓地面紋理或物件排列成為畫面重點。 |
| 2 | 仰拍 Low-angle Shot | 降低手機高度向上拍，表現人物或建築的高大感。 |
| 3 | 近拍 Close-up | 選擇葉片、小物或花朵，讓主要細節清楚，背景保留環境線索。 |
| 4 | 遠景 Wide Shot | 同一景物拍兩張：地平線置中、地平線在三分線；比較天空與地面的份量。 |
| 5 | 光影 Light and Shadow | 以樹影、窗影或斑駁光點構成圖案，讓影子也成為主角。 |
| 6 | 倒影 Reflection | 使用既有水面、玻璃或鏡面，調整高度尋找完整或抽象的倒影。 |
| 7 | 逆光 Backlighting | 光源在主體後方，選擇表現剪影、輪廓或透光質感。 |
| 8 | 對稱 Symmetry | 尋找左右或上下對稱，注意拍攝位置與水平。 |

| 10 | L 型 L-shaped Composition | 以牆角、桌緣或人物姿態形成 L 型，觀察空白區域如何平衡。 |
| 11 | 放射 Radial Composition | 找到向中心聚集或向外延伸的線條，例如傘骨、輪輻。 |
| 12 | 拼接 Panorama Stitching | 固定拍攝位置與焦段，有順序拍攝相互重疊的畫面，再進行拼接。 |

| 14 | 環形框景 Circular Framing | 透過圓窗或圓形物件取景，框內主體須清楚可辨。 |
| 15 | 速度感 Motion / Panning | 拍攝安全的移動主體，嘗試凝結動作或追隨拍攝；後製模糊另作比較。 |
| 16 | 藍天 Sky Photography | 讓天空占較大比例，以雲、建築或小人物提供視覺焦點。 |
| 17 | 綠草 Grass / Texture | 觀察草的紋理、層次與光線，避免只有沒有重點的一片綠。 |
| 18 | 人物特寫 Portrait Close-up | 表現眼神、表情或局部特徵，拍攝前取得同意。 |
| 19 | 擺拍 Still-life Arrangement | 用文具、落葉或日用品安排主次、色彩與疏密。 |
| 20 | 錯位 Forced Perspective | 利用前後距離與視線對齊，拍出巨人、迷你人或托住建築的效果。 |
| 21 | 間接觀看 Frame within a Frame | 透過鏡子或另一支手機畫面看見被攝者，交代觀看者與被攝者的關係。 |

**拼接補充：**不必固定九張；先從單排開始。相鄰照片約重疊 25%～40%，並盡量維持曝光與拍攝角度連貫，再挑戰多排拼接。[Adobe 全景拼接示範](https://www.adobe.com/learn/photoshop/web/photoshop-panorama)

原有「愈高愈好、趴地、跳下、轉椅」改為安全調整機位；倒影使用現成水面或鏡面即可，不必在走道灑水。

**單元三－3｜修圖與合成 Photo Editing & Compositing**

**一、學習目標**

- 理解圖層、選取範圍與遮色片的用途。
- 完成裁切、曝光與色彩調整。
- 運用去背、修補、變形與混合模式進行創作。
- 讓不同來源的照片在透視、光影與色彩上協調。

**二、先建立可以修改的工作流程**

> **保留原圖 → 建立工作檔 → 基本校正 → 局部修整 → 創意合成 → 檢查 → 輸出**

三個重要概念：

- **圖層 Layers**：將不同素材分開管理。
- **選取範圍 Selection**：指定這次要處理的區域。
- **遮色片 Layer Mask**：控制圖層哪些部分顯示，保留被隱藏的影像內容。

遮色片可記成「**白色顯示、黑色隱藏、灰色部分顯示**」，適合反覆修整去背邊緣。[Photopea 遮色片說明](https://www.photopea.com/learn/masks)

**三、基本修圖：先處理整體，再處理局部**

建議順序：

1. 裁切與拉正。
2. 調整整體亮度及明暗層次。
3. 修正白平衡與偏色。
4. 微調對比及彩度。
5. 處理局部干擾。
6. 檢查細節並輸出。

可使用調整圖層保留後續修改空間，並以遮色片限制調整區域。[Photopea 調整與濾鏡](https://www.photopea.com/learn/adjustments-filters)、[Adobe 調整圖層教學](https://www.adobe.com/learn/photoshop/web/adjustment-layer)

**四、將原有工具清單整理成學習階梯**

| 階段 | 技能 | 課堂任務 | 檢查重點 |
|---|---|---|---|
| 基礎 | 裁切 Crop | 同一照片做兩種構圖 | 主體更明確了嗎？ |
| 基礎 | 曲線 Curves | 調整偏暗照片的明暗層次 | 亮部與暗部是否仍有細節？ |
| 基礎 | 色相／飽和度 Hue/Saturation | 改變一項物件的顏色 | 是否誤改其他區域？ |
| 基礎 | 去背與遮色片 | 將人物或商品放入新背景 | 邊緣有沒有白邊、缺角？ |
| 進階 | 內容感知填滿 | 移除背景中的小型干擾物 | 紋理、地面線條是否連續？ |
| 進階 | 仿製印章 Clone Stamp | 修補或複製局部內容 | 是否出現明顯重複圖樣？ |
| 進階 | 透視與變形 Transform | 校正建築或創作誇張比例 | 透視是否符合創作目的？ |
| 進階 | 混合模式 Blend Modes | 將紋理與照片疊加 | 是否仍看得清楚主題？ |
| 進階 | 局部換色 | 調整髮色或衣服顏色 | 髮絲、皮膚與背景有沒有被誤改？ |
| 延伸 | Photomerge | 拼接校園全景 | 接縫、重影與變形是否明顯？ |
| 延伸 | 液化 Liquify | 製作物件的趣味造型 | 變形是否破壞背景？ |
| 延伸 | 動態模糊 Motion Blur | 為背景加入方向感 | 模糊方向是否符合動作？ |

仿製印章會複製取樣區域的像素，因此要注意紋理接續與重複痕跡。[Photopea 基本修圖工具](https://www.photopea.com/learn/bt-basic)

**五、合成自然的五個檢查點**

以下作為課堂檢查表：

| 檢查項目 | 問自己 |

| 比例與透視 | 人物大小、地平線與拍攝高度是否合理？ |

**單元三－4｜商品攝影 Product Photography：讓照片說明商品的價值**

**一、商品照片需要回答什麼？**

> **它是什麼？有什麼特色？適合誰？可以怎麼使用？**

商品攝影可以延續前兩個單元：先安排光線與構圖，再用適量修圖清楚呈現商品。

商業攝影的應用包含商品、食物、時尚、建築空間及形象人像等；本單元聚焦學生能自行完成的小型商品與食物拍攝。

**二、同一商品，拍出不同用途**

| 照片類型 | 目的 | 拍攝重點 |
|---|---|---|
| 商品主圖 | 清楚辨識商品 | 完整外觀、簡潔背景 |
| 細節圖 | 展示材質與特色 | 紋理、接縫、按鍵、商標 |
| 情境圖 | 呈現使用方式 | 商品與環境、人物的關係 |
| 比例圖 | 說明實際大小 | 與手部或熟悉物件比較 |
| 創意形象圖 | 傳達品牌個性 | 色彩、道具、概念與留白 |

商品攝影應先確認影像用途，再決定場景、光線與拍攝安排。[Adobe 商品攝影指南](https://www.adobe.com/creativecloud/photography/type/product-photography.html)

**三、低成本拍攝布置**

課堂可準備：

- 一支手機。
- 一張桌子與窗邊光線。
- 白色或素色背景紙。
- 白色厚紙板，作為反光板。
- 黑色厚紙板，供調整反射與暗部。
- 手機支架或腳架。
- 與商品用途相關的少量道具。

**基本安排：商品放桌面，窗光從側前方照入，另一側放白卡。**

白色反光板可將光反射至較暗的一側，改善陰影亮度，也較不易引入明顯色偏。[毫米攝影：反光板與商品打光](https://homietw.com/商品攝影打光教學-新手也能輕鬆駕馭的技巧大公開/)

**四、用比較實驗理解打光**

建議讓學生固定手機與商品，只改變一個條件：

| 實驗 | 比較方式 | 觀察問題 |
|---|---|---|
| 光線方向 | 順光、側光、逆光各一張 | 哪一張最能表現立體感？ |
| 補光 | 不放白卡／放白卡 | 陰影與細節有什麼差異？ |
| 光線柔硬 | 直射光／經適當柔化的光 | 影子邊緣如何改變？ |
| 背景 | 白色／深色／情境背景 | 哪一種最符合商品定位？ |
| 反光控制 | 改變商品、相機或紙板位置 | 商標與材質是否更清楚？ |

拍攝玻璃或金屬時，尤其要觀察表面映出的周圍環境；若商標被亮斑遮住，先調整角度與反射位置。

**五、食物攝影：呈現質感、份量與食用情境**

| 拍攝角度 | 適合嘗試的食物 | 觀察重點 |
|---|---|---|
| 俯拍 | 餐盤、便當、桌面組合 | 排列、色彩與幾何形狀 |
| 約 45 度 | 一般餐點、碗裝食物 | 食物與容器的立體關係 |
| 接近平視 | 漢堡、蛋糕、層次飲品 | 高度、切面與堆疊 |

角度不必固定，先判斷食物最值得呈現的特色在哪裡。

把原有「切、正在使用、生活感」展開成三種敘事：

- **切開**：呈現內餡、厚度與不同層次。
- **動作**：倒飲料、夾起食物、切下一口，讓畫面帶出使用情境。
- **生活感**：加入手部、餐具或適量道具，交代正在享用的場景。

建議練習同一道食物的「完整外觀、細節、食用動作」三張照片，並維持一致色調。原有[食物攝影文章](https://tw.cyberlink.com/blog/photo-editing-tips/2434/food-photography)可保留為延伸閱讀。

**六、整合實作：替一項商品拍攝小型宣傳組圖**

選擇飲料、文具、點心、手作品或生活小物，先完成一句拍攝企畫：

> 我要向＿＿＿介紹＿＿＿，透過＿＿＿的畫面風格，表現它的＿＿＿特色。

建議繳交五張成品：

1. 商品主圖。
2. 材質或功能細節圖。
3. 使用情境圖。
4. 留有文案空間的宣傳圖。
5. 創意形象圖。

另附一組「補光前／補光後」比較，與簡單布光示意。商品修圖以準確呈現為原則，避免改變商品實際顏色、比例或功能。

**三個單元共用的建議評量方式**

| 項目 | 比例 | 評量重點 |
|---|---:|---|
| 主題與表達 | 25% | 作品是否有明確主角與想法？ |
| 構圖與背景 | 25% | 畫面安排是否能引導觀看？ |
| 光線與技術 | 25% | 對焦、曝光、光影是否符合目的？ |
| 創意與完成度 | 15% | 是否有自己的安排與細節處理？ |
| 過程與說明 | 10% | 是否保留原圖、呈現比較並說明選擇？ |
