4-1.1

系統軟體

用來控制或維護電腦設備運作的程式，分成作業系統、公用程式、語言翻譯程式三類。

重點

作業系統（Operating System, OS）

作業系統居中協調、管理電腦的軟硬體資源，是使用者和電腦硬體之間的溝通橋樑。電腦和手機都要裝作業系統。

作業系統開發維護者開放原始碼適用設備一句話記住它
Windows微軟否電腦、行動裝置Windows 10 可跨平台
UNIX貝爾實驗室否（早期有開放）電腦用 C 語言開發，可攜性佳，常用在大型電腦
LinuxLinux 基金會是電腦、行動裝置Linus Torvalds 以 UNIX 為基礎開發；衍生版有 Red Hat、Fedora、Ubuntu
macOS蘋果否電腦率先使用圖形使用者介面（GUI），只能在蘋果電腦上用
AndroidGoogle是行動裝置基於 Linux 核心；用 Play 商店要 Google 授權
iOS蘋果否行動裝置封閉系統，只能從 App Store 下載軟體

課外閱讀：單人單工（MS-DOS）、單人多工（Windows、macOS、Android、iOS）、多人多工（UNIX、Linux、Windows Server）。

實驗一：CPU 排程，誰先用 CPU？

電腦裡同時有好幾個程式在等 CPU，但 CPU 一次只能做一件事。作業系統要決定順序，這就是「分配與管理資源」。調整下面程式的到達時間和需要的時間，選一種排程方法，按「播放」看 CPU 怎麼分配。

程式幾時到達需要 CPU 時間
時間0
CPU 正在執行
排隊等待
已完成
按「播放」開始，或按「下一步」一格一格看。
觀察任務
  1. 三種方法各播一次，哪一種的「平均等待時間」最短？
  2. 把 Chrome 的需要時間改成 12，再用 FCFS 播放。後面的程式要等多久？
  3. 用 RR 播放，看看是不是每個程式都很快就輪到。這就是為什麼我們覺得電腦能「同時」開好幾個程式（單人多工）。

實驗二：磁碟重組，檔案為什麼會變慢？

下面每一格是磁碟上的一個磁區。檔案刪掉後會留下空洞，新檔案只好拆開來塞進空洞，這就是「磁碟碎片」。讀取碎片化的檔案時，讀寫頭要跳來跳去，所以會變慢。試試「讀取檔案」，再按「重組並最佳化」比較看看。

觀察任務
  1. 讀取「F」，讀寫頭跳了幾次？記下來。
  2. 按「重組並最佳化磁碟機」，再讀取一次 F，跳躍次數變成多少？
  3. 刪掉幾個檔案、再存新檔案，看碎片怎麼又出現。這就是 Windows 每週自動最佳化磁碟的原因。

公用程式（工具程式）

用來維護及支援電腦運作。常考的配對：

公用程式做什麼
磁碟清理清除資源回收筒、暫存檔等不需長期保存的檔案
磁碟檢查錯誤檢查磁區是否損毀並自動修復
修復磁碟機備份系統檔，電腦故障時還原到建立的時間點
重組並最佳化磁碟機把分散的資料存到連續磁區，加快存取速度（112 商管群考過）
磁碟格式化清除資料並分割磁碟
系統還原回到先前運作正常的狀態
驅動程式讓作業系統能辨識、管理與操控硬體

重點

語言翻譯程式：編譯器與直譯器

電腦只看得懂機器語言。我們寫的程式要經過語言翻譯程式轉成機器語言，電腦才能執行。

編譯器（Compiler）
像把整本書翻譯好再出版。先檢查、翻譯整個程式，有錯就一行都不執行。例：GCC 把 C 語言翻成機器語言。
直譯器（Interpreter）
像即席口譯，翻一句、說一句。一行一行執行，遇到錯誤才停下來。例：瀏覽器執行 JavaScript、Python。

直譯器實驗：alert("fefe");

JavaScript 是由瀏覽器裡的直譯器一行一行執行的。先按「直譯執行」看看會跳出什麼，再改改看程式。左邊的行號會顯示目前執行到哪一行。

執行結果
按下「直譯執行」或「編譯執行」開始。
觀察任務
  1. 把 "fefe" 改成自己的名字，再執行一次。
  2. 載入「範例 2」，分別按「直譯執行」和「編譯執行」。哪一種有跳出前兩個視窗？為什麼？
  3. 把 aler 改回 alert，再試一次。
在真正的瀏覽器裡玩 在電腦上的 Chrome 或 Edge 開任一個網頁，按 F12（或 Ctrl+Shift+J）打開「主控台 Console」，輸入下面這行後按 Enter，就會跳出瀏覽器真正的提示視窗： 
alert("fefe");
第一次貼上程式碼時，Chrome 可能會要求先輸入 allow pasting，自己打字輸入就不需要。

這個練習區支援 alert(...)、console.log(...)、let 變數 = ... 與加減乘除，是為了上課示範做的簡化版直譯器。進階挑戰：到 WebVM 用 GCC 編譯 C 程式（如果映像檔有內建 gcc）：

printf '#include <stdio.h>\nint main(){ puts("fefe"); return 0; }\n' > hi.c
gcc hi.c -o hi     # 編譯：把 C 翻成機器語言
./hi               # 執行翻好的程式
4-1.2

應用軟體

為了處理或解決特定問題而開發的軟體，分成套裝軟體和專案開發軟體；裝在手機上的叫 App。

套裝軟體針對大多數使用者的需求設計。例：威力導演、Photoshop、CorelDRAW、Microsoft Office、OpenOffice。
專案開發軟體針對特定機構的個別需求設計。例：餐廳點菜系統、校務行政系統、台灣高鐵網路訂位系統。
手機應用軟體（App）從 Play 商店或 App Store 下載。例：翻譯程式、Pokémon Go、Google 地圖。

4-2

網路

依涵蓋範圍分成區域網路（LAN）和廣域網路（WAN）；網際網路（Internet）是橫跨全世界的超大型廣域網路。

區域網路 LAN限定範圍內：公司、學校電腦教室、同一棟大樓。
廣域網路 WAN廣闊地理範圍：各地戶政機關的網路、跨國企業連各地分公司。
網際網路 Internet全球各地的網路連在一起，任何連上的電腦或手機都能互相溝通。

4-3

雲端服務

透過網路從遠端取用系統平台提供的服務。工程師畫圖時常用雲朵代表網路，所以叫「雲端」。

重點

使用者端與雲端；雲端資源的三層架構

IaaS　基礎建設即服務出租儲存設備、伺服器、網路建設、資安設備。例：Google 機房、中華電信、AT&T、租用雲端儲存空間。
PaaS　平台即服務出租開發、測試與執行程式的平台（作業系統、開發工具、資料庫）。例：Oracle Cloud、Microsoft Azure、AWS。
SaaS　軟體即服務線上直接使用的應用軟體，運算多在雲端完成。例：Gmail、LINE、YouTube、Google 地圖。

考前特別注意
  • 驅動程式、磁碟工具、編譯器、iOS 都是系統軟體。
  • 校務行政、銀行、報稅、會計系統是應用軟體。
  • 沒有「多人單工」；iOS 是單人多工。
  • 範圍小到大：LAN < MAN < WAN < Internet。
  • SaaS 不能離線用，伺服器越遠傳輸越慢。
